# 🎓 CampusTrack – Intelligent Lost & Found Locator

CampusTrack is a web-based **Lost and Found Management System** designed for college campuses. It provides a centralized platform where students can report lost or found items, browse available reports, track their submissions, and communicate regarding recovered items.

The project was developed as part of the **Infosys Internship 6.0** program with the aim of making the traditional lost-and-found process faster, organized, and easier to manage.

---

## 📌 Problem Statement

In colleges, students frequently lose personal belongings such as ID cards, wallets, books, electronic devices, keys, and other items.

Traditional lost-and-found methods mainly depend on notice boards, class groups, or word-of-mouth communication. This makes finding lost belongings difficult and inefficient.

**CampusTrack** provides a digital platform where lost and found items can be reported and searched from one centralized system.

## ⚙️ How CampusTrack Works

### 1. User Registration/Login
Users create an account or log in to access the CampusTrack system.

### 2. Report an Item
A user can submit information about a **lost** or **found** item, including relevant details.

### 3. Browse Items
Users can browse the available lost and found reports to check whether their missing item has been reported.

### 4. View Item Details
Detailed information about a selected lost or found item can be viewed through the item details page.

### 5. Track Reports
Users can monitor the reports they have submitted through the **My Reports** section.

### 6. Admin Management
The administrator can monitor and manage reports and related activities using the admin dashboard.

## 🔥 Firebase Setup

To use Firebase services:

1. Create a Firebase project.
2. Enable **Firebase Authentication**.
3. Create a **Cloud Firestore** database.
4. Enable **Firebase Storage** if required for item images.
5. Add your Firebase configuration to the appropriate JavaScript configuration file.
6. Configure the required Firebase security rules.

> ⚠️ Do not commit private credentials, service-account files, or other sensitive configuration information to a public GitHub repository.
